## For a New AI Chat or Agent Session

Use this instruction:

> Read `START_HERE.md`, then `MEOS/20_PROJECT_BOOTSTRAP.md`, `PROJECT_CHARTER.md`, and `CONTEXT_INDEX.yaml`. Load the minimum authoritative context for the current task, summarize the verified project state, identify missing inputs, and continue from the next priority without inventing requirements.

Do not rely on previous chat memory as the source of truth. Repository artifacts, current tasks, executable checks, and recorded evidence are authoritative.
