# Motiflow Engineering Operating System (MEOS)

## Purpose
This document is the mandatory entry point for every human engineer and AI agent.

## Mission
Build Motiflow as an AI-native creative workflow platform using predictable engineering practices.

## Read Order
1. PROJECT_CHARTER.md
2. MEOS/*
3. Architecture
4. PRD
5. Current task

## Non-Negotiable Rules
- Never bypass architecture.
- Never invent APIs or schemas.
- Every task starts with a plan.
- Every change must include tests where applicable.
- Every architectural change requires an ADR.
- Documentation is part of the deliverable.

## Engineering Flywheel
Think → Plan → Build → Test → Review → Improve → Repeat.

## Definition of Ready
Requirements, acceptance criteria, dependencies, and contracts are available.

## Definition of Done
Build passes, tests pass, docs updated, review completed.

## Stop Conditions
Stop and escalate when requirements conflict, architecture would be violated, or human approval is required.

## Success Metric
No task is complete until it satisfies all mandatory gates, not just feature implementation.
